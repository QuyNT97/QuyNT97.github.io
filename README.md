# QuyNT97.github.io

Personal GitHub Pages profile for [QuyNT97](https://github.com/QuyNT97).

Live site: **https://quynt97.github.io/** (after deploy)

## Deploy

1. Push this repo to `QuyNT97/QuyNT97.github.io` on the `main` branch.
2. In GitHub → **Settings → Pages**, set source to **Deploy from branch** → `main` → `/ (root)`.
3. Wait a minute for the workflow; open the URL above.

## Local preview

```bash
npx --yes serve .
# or: python3 -m http.server 8080
```

Open `http://localhost:3000` (or `:8080`).
